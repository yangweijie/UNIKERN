## R8.5 拒绝分支的设备级证据（probe/phase16_residency_refuse.cpp）

生成程序自身的 hipMalloc 路径在本机硬件上不可能产生非设备驻留（这正是 migrations=0 的happy path），故用 hipHostMalloc 的 host 指针直接代位非设备驻留条件，验证守卫的探测+拒绝分支在真实 runtime 上触发。守卫函数体与生成程序发射的 uk_resident 逐字一致。

$ "/d/Program Files/AMD/ROCm/7.1/bin/hipcc.exe" probe/phase16_residency_refuse.cpp -O3 --offload-arch=gfx1032 -o uk_run/p85_refuse.exe
(compile rc=0)
$ ./uk_run/p85_refuse.exe; echo exit=$?
PROBE hipMalloc residency rc=0 (expect 0 = hipMemoryTypeDevice)
UNIKERN_ERROR what=oversubscription ptr=hipHostMalloc h type=1 (managed/host residency is oversubscription; explicit streaming is the only path; R8.5)
PROBE hipHostMalloc residency rc=5 (expect 5 = oversubscription refusal)
exit=5
